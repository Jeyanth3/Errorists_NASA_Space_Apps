# Demo

Space Apps allows **either** a ≤30-second video **or** ≤7 slides (title + intro included). English, or English
subtitles. Pick one; a strong demo lifts the Presentation score.

## Option A - 30-second video (recommended)

| sec | screen | voice-over |
|---|---|---|
| 0-4 | Moon base render (own image, no NASA logo) | "Future Moon bases may breathe 30% oxygen at low pressure, in one-sixth gravity." |
| 4-9 | Search box returning ISS fire papers | "Search NASA's fire experiments and you get results from orbit, in normal air." |
| 9-17 | Mission Explorer: pick Moon base → all EXTRAPOLATED, red banner | "FireWise checks the physics. For the Moon, none of NASA's 1,065 runs is direct evidence." |
| 17-23 | Condition certificate (gravity ❌, O₂ fraction ❌) → Atmosphere Map stars vs dots | "It shows exactly what differs - and where nothing has been tested." |
| 23-28 | Ask FireWise answer with PSI links | "Every answer is built from NASA data, with its source." |
| 28-30 | Logo + URL | "FireWise. Know what the evidence really says." |

Record with OBS / QuickTime at 1080p, add subtitles, upload to YouTube (unlisted is fine if the link is public).

## Option B - 7 slides

1. Title - FireWise, team, challenge
2. Problem - habitat atmosphere vs where NASA tested (Atmosphere Map screenshot)
3. Why search fails - same keywords, wrong physics
4. MACE - three scores + evidence levels + certificate
5. Live result - Moon base PMMA: 0 DIRECT, gaps shown; ISS suppression: FLEX DIRECT
6. Trust - 1,065 runs, provenance, data conflicts found, benchmark vs BM25
